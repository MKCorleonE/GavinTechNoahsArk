## 一、算法题的 16 大核心模块

算法题没有全球统一的分类标准，但从 LeetCode、牛客以及常见的大厂笔试面试来看，可以将高频内容整理为以下 16 类。

| 分类 | 核心思想 | 典型题目 |
|---|---|---|
| 1. 模拟与枚举 | 按规则执行，遍历可能性 | 螺旋矩阵、整数反转 |
| 2. 哈希表 | 用空间换时间，快速查找 | 两数之和、字母异位词 |
| 3. 双指针与滑动窗口 | 利用指针移动减少重复计算 | 三数之和、最长无重复子串 |
| 4. 排序与二分查找 | 排序后利用有序性缩小范围 | 搜索旋转数组、寻找峰值 |
| 5. 前缀和与差分 | 预处理累计信息，快速计算 | 子数组和为 K、区间加法 |
| 6. 栈、队列与单调结构 | 维护特定的访问或大小顺序 | 有效括号、每日温度 |
| 7. 堆与优先队列 | 快速获取最大值或最小值 | 数组中第 K 大元素 |
| 8. 链表 | 操作节点与指针关系 | 反转链表、环形链表 |
| 9. 二叉树 | 递归、遍历、树形结构处理 | 最近公共祖先、路径总和 |
| 10. DFS、BFS 与回溯 | 系统性探索状态空间 | 全排列、岛屿数量 |
| 11. 贪心算法 | 每一步选择当前最优策略 | 跳跃游戏、分发饼干 |
| 12. 动态规划 DP | 利用历史结果减少重复计算 | 背包问题、最长递增子序列 |
| 13. 图论 | 处理节点间的连接与路径 | 最短路径、拓扑排序 |
| 14. 并查集 | 高效维护元素的连通关系 | 冗余连接、省份数量 |
| 15. 字符串算法 | 处理模式匹配与字符序列 | KMP、最长回文子串 |
| 16. 数学与位运算 | 运用数学性质和二进制技巧 | 快速幂、只出现一次的数字 |

**注意：**

这 16 类是为了方便备考而划分的知识模块，并不是严格互斥的分类。

例如：

- 滑动窗口可以结合哈希表。
- 二叉树问题可以使用动态规划。
- 图论问题可以使用 BFS 或 DFS。
- 二分查找可以与贪心、动态规划结合。
- 回溯通常通过 DFS 实现。

一道题可能同时涉及多种算法和数据结构。

## 二、算法知识体系的三个层次

理解算法，需要区分三个概念：

1. 算法思想（Algorithm Paradigm）
2. 解题技巧（Algorithmic Technique）
3. 数据结构（Data Structure）

### 第一层：算法思想

决定一个问题应该如何解决。

主要包括：

- **动态规划（Dynamic Programming）**
  - 将问题拆分为具有重叠性质的子问题。
  - 存储已经计算过的结果。
  - 常用于最优化、计数和可行性问题。

- **贪心算法（Greedy Algorithm）**
  - 每一步做出当前最优选择。
  - 需要证明局部最优可以导向全局最优。

- **分治算法（Divide and Conquer）**
  - 将大问题拆成若干小问题。
  - 分别解决后合并结果。
  - 典型应用：归并排序、快速排序。

- **回溯算法（Backtracking）**
  - 尝试不同的选择。
  - 当发现当前路径不满足要求时撤销选择。
  - 典型应用：全排列、N 皇后。

- **搜索算法（Search）**
  - 按照一定规则探索状态空间。
  - 主要包括 DFS 和 BFS。
  - 典型应用：图遍历、迷宫寻路。

### 第二层：解题技巧

决定具体如何高效计算。

| 技巧 | 主要用途 |
|---|---|
| 双指针 | 减少嵌套循环，处理有序数组或序列 |
| 滑动窗口 | 处理连续子数组、连续子串 |
| 二分查找 | 在具有单调性的搜索空间中查找 |
| 前缀和 | 快速计算区间和 |
| 差分数组 | 高效处理批量区间更新 |
| 单调栈 | 寻找下一个更大或更小的元素 |
| 单调队列 | 维护滑动窗口中的最值 |
| 快慢指针 | 判断链表是否有环、寻找中点 |
| 位运算 | 利用二进制性质优化计算 |

### 第三层：数据结构

决定数据如何组织和存储。

| 数据结构 | 核心特征 |
|---|---|
| 数组（Array） | 支持随机访问 |
| 链表（Linked List） | 通过指针连接节点 |
| 哈希表（Hash Table） | 平均 O(1) 查找 |
| 栈（Stack） | 后进先出 LIFO |
| 队列（Queue） | 先进先出 FIFO |
| 堆（Heap） | 高效获取极值 |
| 二叉树（Binary Tree） | 层次化节点结构 |
| 图（Graph） | 表达节点之间的复杂关系 |
| 并查集（Union-Find） | 维护连通分量 |
| 字典树（Trie） | 高效存储和匹配字符串前缀 |

### 三个层次如何结合？

例如：

**题目：给定整数数组，寻找和为目标值的两个数字。**

方法一：暴力枚举

- 遍历所有可能的数字组合。
- 时间复杂度：O(n²)
- 空间复杂度：O(1)

方法二：哈希表

- 遍历数组。
- 记录已经访问过的数字。
- 检查当前数字的补数是否已经出现。
- 平均时间复杂度：O(n)
- 空间复杂度：O(n)

方法三：双指针

- 如果数组已经有序，可以使用左右双指针。
- 根据当前两数之和与目标值的关系移动指针。
- 时间复杂度：O(n)
- 额外空间复杂度：O(1)

如果原数组无序且需要先排序，则必须额外考虑排序成本。

**核心结论：同一个问题可以使用不同的算法和数据结构。**

面试官经常追问：

- 有没有更高效的方法？
- 能否降低时间复杂度？
- 能否降低空间复杂度？
- 为什么这种算法一定正确？

## 三、如何根据题目特征判断使用什么算法？

这是算法刷题中最重要的能力之一。

| 题目出现的特征 | 优先考虑 |
|---|---|
| 连续子数组、连续子串 | 滑动窗口、前缀和 |
| 最大收益、最少次数、最优值 | 贪心、动态规划、二分答案 |
| 所有排列、所有组合、所有方案 | 回溯、DFS |
| 最短步数、最少操作次数 | BFS、动态规划 |
| 有序数组、高效查找 | 二分查找、双指针 |
| 区间求和、区间更新 | 前缀和、差分 |
| 下一个更大元素、最近更小元素 | 单调栈 |
| 前 K 大、动态最小值 | 堆 |
| 连通块、朋友圈、关系合并 | DFS、BFS、并查集 |
| 依赖关系、任务执行顺序 | 拓扑排序 |
| 字符串匹配与对齐 | 双指针、字符串算法、DP |
| 树上的路径、子树信息 | DFS、递归、树形 DP |

注意：题目中的关键词只能帮助确定候选算法，不能直接证明某种算法一定适用。

### 贪心、动态规划和二分答案的区别

这三种算法经常用于最优化问题，但思路完全不同。

#### 1. 贪心算法

**核心思想：每一步做当前最优选择。**

基本流程：

1. 分析当前有哪些选择。
2. 选择局部最优方案。
3. 更新当前状态。
4. 重复直到问题解决。

关键问题：

> 如何证明局部最优最终能够得到全局最优？

#### 2. 动态规划

**核心思想：利用子问题的结果构造更大问题的答案。**

基本流程：

1. 定义 DP 状态。
2. 推导状态转移方程。
3. 设置初始状态。
4. 确定计算顺序。
5. 返回目标状态。

关键问题：

> 当前状态如何从已经计算过的状态推导出来？

#### 3. 二分答案

**核心思想：不直接寻找最优值，而是判断候选答案是否可行。**

基本流程：

1. 确定答案的搜索范围。
2. 选择中间值 mid。
3. 判断 mid 是否满足约束条件。
4. 根据单调性缩小搜索范围。
5. 最终找到最优答案。

关键问题：

> 问题是否具有单调可行性？

例如：如果某个限制值可以完成任务，那么所有更宽松的限制值是否也可以完成？

## 四、算法学习的优先级

建议将算法学习划分为三个阶段。

### 第一阶段：基础高频题型

**目标：能够快速识别常见数组与字符串问题，并熟练实现基本算法。**

学习内容：

- [ ] 数组与哈希表
- [ ] 双指针
- [ ] 滑动窗口
- [ ] 排序
- [ ] 二分查找
- [ ] 前缀和与差分
- [ ] 栈与队列
- [ ] 链表

学习重点：

- 能独立编写代码。
- 熟悉 Python 常用数据结构。
- 理解基本时间复杂度。
- 避免不必要的嵌套循环。

### 第二阶段：核心算法思想

**目标：能够独立分析复杂问题，设计搜索和状态转移过程。**

学习内容：

- [ ] 递归
- [ ] 二叉树遍历
- [ ] DFS
- [ ] BFS
- [ ] 回溯
- [ ] 贪心算法
- [ ] 动态规划基础
- [ ] 0/1 背包与完全背包

学习重点：

- 理解递归调用过程。
- 理解 DFS 与 BFS 的区别。
- 掌握回溯模板。
- 学会设计 DP 状态。
- 能够判断何时使用贪心或 DP。

### 第三阶段：进阶与综合问题

**目标：具备解决中高难度算法题及综合算法题的能力。**

学习内容：

- [ ] 图的表示与遍历
- [ ] 最短路径算法
- [ ] 拓扑排序
- [ ] 并查集
- [ ] 堆与优先队列
- [ ] 单调栈与单调队列
- [ ] 树形 DP
- [ ] 区间 DP
- [ ] 字符串匹配算法
- [ ] 数学与数论
- [ ] 位运算
- [ ] 复杂算法的时间和空间优化

学习重点：

- 能够组合多种算法。
- 理解算法正确性的证明。
- 熟悉常见优化手段。
- 能独立解决中等难度问题，并尝试困难题。

## 五、算法刷题的正确方法

### 1. 第一遍：按照算法分类刷题

学习某一种算法时，集中练习同类型题目。

推荐步骤：

1. 理解算法的核心思想。
2. 学习适用场景。
3. 手动推导一个简单例子。
4. 掌握 Python 基础模板。
5. 完成简单题。
6. 完成中等难度题。
7. 总结典型题型与常见变形。

第一遍的目标不是记住具体答案，而是掌握算法模式。

### 2. 第二遍：混合刷题

完成基础分类学习后，开始不看标签刷题。

训练重点：

- 从题目中提取关键信息。
- 分析输入规模和约束条件。
- 判断适合的算法。
- 估计时间与空间复杂度。
- 独立完成代码实现。

**真实面试不会提前告诉你题目属于哪一种算法。**

因此，混合刷题是从「会套模板」走向「独立解题」的重要阶段。

### 3. 第三遍：限时模拟面试

模拟真实笔试与面试环境。

建议每道题按照下面的步骤处理：

1. 理解题意，确认边界条件。
2. 首先提出暴力解法。
3. 分析暴力解法的复杂度。
4. 尝试优化算法。
5. 编写可运行的代码。
6. 测试特殊情况。
7. 解释算法的正确性与复杂度。

重点训练：

- 解题速度
- 思维表达
- 代码准确率
- 边界条件处理
- 时间复杂度优化

## 七、算法学习的最终目标

算法能力可以划分为四个层次：

| 层次 | 能力描述 |
|---|---|
| Level 1 | 看得懂别人写的算法代码 |
| Level 2 | 知道算法类型后可以独立实现 |
| Level 3 | 不看题目标签也能判断合适算法 |
| Level 4 | 能设计、证明并优化复杂问题的解法 |

**大厂算法面试的核心目标是达到 Level 3，并逐步具备 Level 4 的能力。**

刷题数量并不直接等于算法能力。

真正需要掌握的是：

- 算法识别能力
- 算法设计能力
- 复杂度分析能力
- 正确性证明能力
- 代码实现能力
- 算法优化能力

> 核心原则：不要只记住一道题怎么做，而要理解为什么使用这种算法，以及什么样的问题可以使用相同的思路。
