## Embedding 是什么
Embedding 可以理解为“把文本映射成数字坐标”的过程。

例如一句话“Python 适合数据分析”，经过 embedding 模型后，会变成一个高维向量（如 768 维、1024 维）。

RAG 里为什么需要 embedding：
1. 计算机更擅长比较数字而不是直接比较自然语言。
2. 语义相近的文本，在向量空间中通常也更接近。
3. 可以支持快速语义检索（不是只靠关键词匹配）。


## 向量是什么
向量是一个有序数字列表，例如：

```text
[0.12, -0.45, 0.98, ...]
```

在 NLP 里，这些数字不是随便生成的，而是模型学习到的语义表示。不同文本会对应不同向量。

## 向量维度是什么
向量维度就是这个数字列表的长度。

例如：
1. 384 维：每个向量有 384 个数。
2. 768 维：每个向量有 768 个数。
3. 1536 维：每个向量有 1536 个数。

维度越高，理论上能表达更细粒度信息，但也会带来更高存储与计算成本。工程上要平衡效果与性能。

## Cosine Similarity（余弦相似度）
余弦相似度（Cosine Similarity）用于衡量两个向量的方向一致性，本质是两个向量夹角的余弦值。

### 详细定义
给定两个向量 $\mathbf{a}$ 和 $\mathbf{b}$，余弦相似度定义为：

$$
\cos(\theta)=\frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|\,\|\mathbf{b}\|}
$$

其中：
1. $\mathbf{a}\cdot\mathbf{b}$ 是点积。
2. $\|\mathbf{a}\|$ 和 $\|\mathbf{b}\|$ 是向量的 L2 范数（长度）。
3. $\theta$ 是两个向量的夹角。

当向量不为零向量时，余弦相似度取值范围是 $[-1,1]$：
1. $1$：方向完全一致。
2. $0$：方向正交（几乎无相关）。
3. $-1$：方向完全相反。

### 理论解释（为什么它适合文本检索）
在 embedding 空间里，向量的长度可能受句子长度、词频或模型尺度影响，但我们往往更关心语义方向是否一致。余弦相似度通过除以两个向量的长度，弱化了模长影响，突出方向信息。

因此在语义检索里，常优先用余弦相似度而不是直接比较欧氏距离。

### 数学展开式
如果

$$
\mathbf{a}=(a_1,a_2,\dots,a_n),\quad \mathbf{b}=(b_1,b_2,\dots,b_n)
$$

则

$$
\mathbf{a}\cdot\mathbf{b}=\sum_{i=1}^{n}a_i b_i
$$

$$
\|\mathbf{a}\|=\sqrt{\sum_{i=1}^{n}a_i^2},\quad
\|\mathbf{b}\|=\sqrt{\sum_{i=1}^{n}b_i^2}
$$

所以

$$
\cos(\theta)=\frac{\sum_{i=1}^{n}a_i b_i}{\sqrt{\sum_{i=1}^{n}a_i^2}\sqrt{\sum_{i=1}^{n}b_i^2}}
$$

### 例子 1：二维向量
设

$$
\mathbf{a}=(1,2),\quad \mathbf{b}=(2,1)
$$

计算：

$$
\mathbf{a}\cdot\mathbf{b}=1\times2+2\times1=4
$$

$$
\|\mathbf{a}\|=\sqrt{1^2+2^2}=\sqrt{5},\quad
\|\mathbf{b}\|=\sqrt{2^2+1^2}=\sqrt{5}
$$

$$
\cos(\theta)=\frac{4}{\sqrt{5}\sqrt{5}}=\frac{4}{5}=0.8
$$

结论：相似度较高，方向比较接近。

### 例子 2：三维向量
设

$$
\mathbf{a}=(1,0,1),\quad \mathbf{b}=(1,1,0)
$$

计算：

$$
\mathbf{a}\cdot\mathbf{b}=1\times1+0\times1+1\times0=1
$$

$$
\|\mathbf{a}\|=\sqrt{1^2+0^2+1^2}=\sqrt{2},\quad
\|\mathbf{b}\|=\sqrt{1^2+1^2+0^2}=\sqrt{2}
$$

$$
\cos(\theta)=\frac{1}{\sqrt{2}\sqrt{2}}=\frac{1}{2}=0.5
$$

结论：有一定相关性，但方向相似程度中等。

### 例子 3：n 维向量（通用）
设

$$
\mathbf{a}=(a_1,a_2,\dots,a_n),\quad \mathbf{b}=(b_1,b_2,\dots,b_n)
$$

则直接代入通用公式：

$$
\cos(\theta)=\frac{\sum_{i=1}^{n}a_i b_i}{\sqrt{\sum_{i=1}^{n}a_i^2}\sqrt{\sum_{i=1}^{n}b_i^2}}
$$

工程里通常用矩阵库一次性批量计算 query 与所有 chunk 向量的余弦相似度，再取 Top-K 作为召回结果。

### 实践注意点
1. 零向量无法计算余弦相似度（分母为 0），要在数据预处理时避免。
2. 若向量先做 L2 归一化，则余弦相似度等价于点积，检索实现更高效。
3. Top-K 检索时，相似度排序应与索引度量方式保持一致（cosine、IP、L2 不要混用）。

```python
import math

def manual_cosine_similarity(vec_a, vec_b):
    """
    纯手工实现余弦相似度，打印每一步的计算细节
    """
    # 1. 计算点积 (分子)
    dot_product = 0
    for i in range(len(vec_a)):
        dot_product += vec_a[i] * vec_b[i]
    print(f"步骤1: 点积 (分子) = {dot_product}")

    # 2. 计算向量A的模长 (分母的一部分)
    norm_a = 0
    for val in vec_a:
        norm_a += val ** 2
    norm_a = math.sqrt(norm_a)
    print(f"步骤2: 向量A的模长 = {norm_a:.4f}")

    # 3. 计算向量B的模长 (分母的一部分)
    norm_b = 0
    for val in vec_b:
        norm_b += val ** 2
    norm_b = math.sqrt(norm_b)
    print(f"步骤3: 向量B的模长 = {norm_b:.4f}")

    # 4. 计算最终相似度
    similarity = dot_product / (norm_a * norm_b)
    print(f"步骤4: 最终相似度 = {similarity:.4f}")
    return similarity

# 举例：两个向量
vec_a = [1, 2, 3]
vec_b = [4, 5, 6]

print("向量A:", vec_a)
print("向量B:", vec_b)
print("--- 计算过程 ---")
similarity = manual_cosine_similarity(vec_a, vec_b)
```

## Euclidean Distance（欧氏距离）
欧氏距离（Euclidean Distance）衡量两个向量在几何空间中的直线距离。

### 详细定义
给定两个向量 $\mathbf{a}$ 和 $\mathbf{b}$，欧氏距离定义为：

$$
d(\mathbf{a},\mathbf{b})=\|\mathbf{a}-\mathbf{b}\|_2
$$

展开后：

$$
d(\mathbf{a},\mathbf{b})=\sqrt{\sum_{i=1}^{n}(a_i-b_i)^2}
$$

它的取值范围是 $[0,+\infty)$：
1. 距离越小，两个向量越接近。
2. 距离为 0，两个向量完全相同。
3. 距离越大，差异越大。

### 理论解释
欧氏距离直接比较“位置差”，所以会同时受方向和长度影响。在文本向量场景里，如果向量尺度差异很大，欧氏距离可能被模长主导，因此常配合归一化使用。

### 例子 1：二维向量
设

$$
\mathbf{a}=(1,2),\quad \mathbf{b}=(4,6)
$$

$$
d=\sqrt{(1-4)^2+(2-6)^2}=\sqrt{9+16}=5
$$

### 例子 2：三维向量
设

$$
\mathbf{a}=(1,0,3),\quad \mathbf{b}=(4,0,-1)
$$

$$
d=\sqrt{(1-4)^2+(0-0)^2+(3-(-1))^2}=\sqrt{9+0+16}=5
$$

### 例子 3：n 维向量（通用）
设

$$
\mathbf{a}=(a_1,a_2,\dots,a_n),\quad \mathbf{b}=(b_1,b_2,\dots,b_n)
$$

$$
d(\mathbf{a},\mathbf{b})=\sqrt{\sum_{i=1}^{n}(a_i-b_i)^2}
$$

### Python 手动实现
```python
import math

def manual_euclidean_distance(vec_a, vec_b):
    if len(vec_a) != len(vec_b):
        raise ValueError("向量维度不一致")

    sum_sq = 0.0
    for i in range(len(vec_a)):
        diff = vec_a[i] - vec_b[i]
        sum_sq += diff * diff
    return math.sqrt(sum_sq)

# 2D
print(manual_euclidean_distance([1, 2], [4, 6]))   # 5.0
# 3D
print(manual_euclidean_distance([1, 0, 3], [4, 0, -1]))  # 5.0
# nD
print(manual_euclidean_distance([1, 2, 3, 4], [2, 1, 5, 0]))
```

## Dot Product（点积）
点积（Dot Product）是两个向量对应元素乘积之和，常用来衡量方向一致程度和投影关系。

### 详细定义
给定

$$
\mathbf{a}=(a_1,a_2,\dots,a_n),\quad \mathbf{b}=(b_1,b_2,\dots,b_n)
$$

点积定义为：

$$
\mathbf{a}\cdot\mathbf{b}=\sum_{i=1}^{n}a_i b_i
$$

它也可以写成：

$$
\mathbf{a}\cdot\mathbf{b}=\|\mathbf{a}\|\,\|\mathbf{b}\|\cos(\theta)
$$

其中 $\theta$ 是两向量夹角。

### 理论解释
1. 点积大：通常表示方向更一致（且模长也较大）。
2. 点积为 0：向量正交。
3. 点积小于 0：方向更相反。

在向量检索中，若向量都做了 L2 归一化，则

$$
\mathbf{a}\cdot\mathbf{b}=\cos(\theta)
$$

此时点积与余弦相似度等价。

### 例子 1：二维向量
设

$$
\mathbf{a}=(1,2),\quad \mathbf{b}=(3,4)
$$

$$
\mathbf{a}\cdot\mathbf{b}=1\times3+2\times4=11
$$

### 例子 2：三维向量
设

$$
\mathbf{a}=(1,0,2),\quad \mathbf{b}=(2,1,3)
$$

$$
\mathbf{a}\cdot\mathbf{b}=1\times2+0\times1+2\times3=8
$$

### 例子 3：n 维向量（通用）
设

$$
\mathbf{a}=(a_1,\dots,a_n),\quad \mathbf{b}=(b_1,\dots,b_n)
$$

$$
\mathbf{a}\cdot\mathbf{b}=\sum_{i=1}^{n}a_i b_i
$$

### Python 手动实现
```python
def manual_dot_product(vec_a, vec_b):
    if len(vec_a) != len(vec_b):
        raise ValueError("向量维度不一致")

    s = 0.0
    for i in range(len(vec_a)):
        s += vec_a[i] * vec_b[i]
    return s

# 2D
print(manual_dot_product([1, 2], [3, 4]))  # 11
# 3D
print(manual_dot_product([1, 0, 2], [2, 1, 3]))  # 8
# nD
print(manual_dot_product([1, 2, 3, 4], [5, 6, 7, 8]))
```

## Dense Vector（稠密向量）
稠密向量（Dense Vector）是指大多数维度都有非零值的向量，通常由神经网络 embedding 模型直接生成。

### 详细定义
设向量维度为 $n$，非零元素个数为 $\text{nnz}(\mathbf{x})$，可定义“稠密度”为：

$$
\rho(\mathbf{x})=\frac{\text{nnz}(\mathbf{x})}{n}
$$

当 $\rho(\mathbf{x})$ 接近 1 时，可认为该向量是稠密的。

说明：稠密/稀疏没有绝对阈值，常根据任务和工程约定判断。

### 理论解释
1. 稠密向量常把语义信息分布在多个维度上，不依赖少量关键词维度。
2. 这种分布式表示通常对语义相似检索更友好。
3. 在 RAG 中，embedding 向量大多属于稠密向量。

### 例子 1：二维向量
$$
\mathbf{x}=(0.6,-1.2)
$$

这里 $n=2$，非零元素个数 $\text{nnz}=2$，所以

$$
\rho=\frac{2}{2}=1.0
$$

可视为稠密向量。

### 例子 2：三维向量
$$
\mathbf{x}=(0.3,0.8,-0.5)
$$

这里 $n=3$，$\text{nnz}=3$，

$$
\rho=\frac{3}{3}=1.0
$$

仍是典型稠密向量。

### 例子 3：n 维向量（通用）
若

$$
\mathbf{x}=(x_1,x_2,\dots,x_n),\quad \rho(\mathbf{x})=\frac{\text{nnz}(\mathbf{x})}{n}
$$

当 $\rho$ 较高（例如远高于 0.5）时，通常可视为稠密向量。

### Python 手动实现
```python
def count_nnz(vec, eps=1e-12):
    c = 0
    for v in vec:
        if abs(v) > eps:
            c += 1
    return c

def density(vec, eps=1e-12):
    if len(vec) == 0:
        raise ValueError("空向量")
    return count_nnz(vec, eps) / len(vec)

def is_dense_vector(vec, threshold=0.7, eps=1e-12):
    return density(vec, eps) >= threshold

# 2D
v2 = [0.6, -1.2]
print(density(v2), is_dense_vector(v2))

# 3D
v3 = [0.3, 0.8, -0.5]
print(density(v3), is_dense_vector(v3))

# nD
vn = [0.1, 0.0, -0.2, 0.5, 0.0, 0.7]
print(density(vn), is_dense_vector(vn))
```

## Sparse Vector（稀疏向量）
稀疏向量是大多数位置为 0、少数位置非零的向量。

典型来源：
1. TF-IDF
2. BM25 相关特征

特点：
1. 更偏关键词匹配。
2. 可解释性通常更强。
3. 常与稠密向量做混合检索（Hybrid Search）。

## 实践中常用的 Embedding 方法
先回答你的问题：BM25 和 TF-IDF 很常用，但严格来说它们更偏“稀疏表示/词法检索”方法，不是现代神经网络语义 embedding（稠密向量）本身。

工程里常见做法是：
1. 稀疏方法（TF-IDF/BM25）负责关键词精确匹配。
2. 稠密方法（Sentence-BERT、BGE、E5 等）负责语义匹配。
3. 二者做混合检索（Hybrid Retrieval）。

### 方法 1：TF-IDF（稀疏表示）
#### 文字解释
TF-IDF 把文档表示为词权重向量。一个词在当前文档出现得越频繁、在整个语料越稀有，权重越高。

#### 数学解释
词项 $t$ 在文档 $d$ 的权重常写为：

$$
\mathrm{TFIDF}(t,d)=\mathrm{TF}(t,d)\cdot\mathrm{IDF}(t)
$$

其中：

$$
\mathrm{TF}(t,d)=\frac{f_{t,d}}{\sum_{t'}f_{t',d}},\quad
\mathrm{IDF}(t)=\log\frac{N}{\mathrm{df}(t)+1}
$$

$f_{t,d}$ 是词频，$N$ 是文档总数，$\mathrm{df}(t)$ 是包含词项 $t$ 的文档数。

#### Python 代码
```python
from sklearn.feature_extraction.text import TfidfVectorizer

docs = [
    "Python is good for data analysis",
    "Python is widely used in machine learning",
    "Java is common in enterprise systems"
]

vectorizer = TfidfVectorizer()
X = vectorizer.fit_transform(docs)  # 稀疏矩阵

print("vocab:", vectorizer.get_feature_names_out())
print("shape:", X.shape)
print("doc0 tf-idf:", X[0].toarray())
```

### 方法 2：BM25（词法检索打分）
#### 文字解释
BM25 是经典检索排序函数，重点解决“词频有收益但递减”和“文档长度归一化”问题。它常用于 first-stage retrieval。

#### 数学解释
给定查询 $q$ 与文档 $D$，BM25 分数为：

$$
\mathrm{score}(D,q)=\sum_{t\in q}\mathrm{IDF}(t)
\cdot
\frac{f(t,D)(k_1+1)}{f(t,D)+k_1\left(1-b+b\frac{|D|}{\mathrm{avgdl}}\right)}
$$

其中：
1. $f(t,D)$ 是词项 $t$ 在文档 $D$ 的词频。
2. $|D|$ 是文档长度，$\mathrm{avgdl}$ 是平均文档长度。
3. $k_1,b$ 是可调参数（常见 $k_1\in[1.2,2.0], b\approx0.75$）。

#### Python 代码
```python
from rank_bm25 import BM25Okapi

documents = [
    "Python is good for data analysis",
    "Python is widely used in machine learning",
    "Java is common in enterprise systems"
]

tokenized_corpus = [doc.lower().split() for doc in documents]
bm25 = BM25Okapi(tokenized_corpus)

query = "python for machine learning".lower().split()
scores = bm25.get_scores(query)

for i, s in enumerate(scores):
    print(i, round(float(s), 4), documents[i])
```

### 方法 3：Word2Vec / FastText（静态词向量）
#### 文字解释
这类方法把“词”映射成固定向量。优点是轻量、可解释；缺点是同一个词在不同上下文向量不变（多义词处理弱于上下文化模型）。

#### 数学解释（以 skip-gram 为例）
目标是最大化中心词 $w_t$ 对上下文词 $w_{t+j}$ 的条件概率：

$$
\max\sum_t\sum_{-c\le j\le c, j\ne0}\log p(w_{t+j}|w_t)
$$

常用 softmax：

$$
p(w_o|w_i)=\frac{\exp(\mathbf{v}'_{w_o}\cdot\mathbf{v}_{w_i})}{\sum_{w}\exp(\mathbf{v}'_w\cdot\mathbf{v}_{w_i})}
$$

#### Python 代码
```python
from gensim.models import Word2Vec

sentences = [
    ["python", "for", "data", "analysis"],
    ["python", "for", "machine", "learning"],
    ["java", "enterprise", "systems"]
]

model = Word2Vec(sentences, vector_size=50, window=3, min_count=1, workers=1)
print("vector dim:", len(model.wv["python"]))
print("similar words to python:", model.wv.most_similar("python", topn=3))
```

### 方法 4：Sentence-BERT（句向量，稠密 embedding）
#### 文字解释
Sentence-BERT 把整句编码成一个稠密向量，直接用于语义检索、聚类、相似度计算。RAG 中非常常见。

#### 数学解释
句子经过编码器得到向量后，常用余弦相似度训练/检索：

$$
\mathrm{sim}(u,v)=\frac{u\cdot v}{\|u\|\|v\|}
$$

训练中常用对比学习目标，让正样本更近、负样本更远。

#### Python 代码
```python
from sentence_transformers import SentenceTransformer
import numpy as np

model = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")
texts = [
    "Python is good for data analysis",
    "Python is used in machine learning",
    "How to cook pasta"
]

emb = model.encode(texts, normalize_embeddings=True)
query = model.encode(["python for ml"], normalize_embeddings=True)

# 手动计算点积（归一化后等价余弦）
scores = np.dot(emb, query[0])
print(scores)
```

### 方法 5：BGE / E5（检索优化的指令型 embedding）
#### 文字解释
BGE、E5 等模型专门为检索优化，通常在多语种和检索基准上效果更好。很多模型要求为 query/document 添加特定前缀。

#### 数学解释
本质仍是在向量空间最小化语义相近样本距离，常见形式是对比损失。以 InfoNCE 为例：

$$
\mathcal{L}=-\log\frac{\exp(\mathrm{sim}(q,d^+)/\tau)}{\exp(\mathrm{sim}(q,d^+)/\tau)+\sum_{d^-}\exp(\mathrm{sim}(q,d^-)/\tau)}
$$

其中 $\tau$ 是温度系数，$d^+$ 为正样本，$d^-$ 为负样本。

#### Python 代码
```python
from sentence_transformers import SentenceTransformer
import numpy as np

# 示例模型名按本地可用环境替换
model = SentenceTransformer("BAAI/bge-small-zh-v1.5")

docs = [
    "Python常用于数据分析和机器学习",
    "向量数据库用于高效相似度检索",
    "番茄炒蛋是一道家常菜"
]

query = "检索和向量数据库有什么关系"

# 许多检索模型建议加前缀，需按模型文档调整
doc_emb = model.encode([f"passage: {d}" for d in docs], normalize_embeddings=True)
q_emb = model.encode([f"query: {query}"], normalize_embeddings=True)

scores = np.dot(doc_emb, q_emb[0])
print(scores)
```

### 实战结论：怎么选
1. 快速基线：BM25 或 TF-IDF，上手快、可解释。
2. 语义检索主线：Sentence-BERT / BGE / E5 稠密向量。
3. 生产常用：稠密 + 稀疏混合召回，再做 rerank。


## Vector Database 是什么
向量数据库是专门用于存储向量并进行近邻检索的系统。

它一般提供：
1. 向量写入和更新。
2. 相似度检索（Top-K）。
3. 元数据过滤（如按文档类型、时间、部门过滤）。
4. 索引能力（如 HNSW、IVF 等）以提升检索速度。

如果把 embedding 比作“把知识翻译成坐标”，那向量数据库就是“在坐标空间里快速找近邻”的引擎。

## 常见向量数据库
### FAISS
Meta 开源库，轻量高效，适合本地实验和原型验证。

### Chroma
开发体验友好，和 Python 生态结合好，适合快速搭建 RAG Demo。

### Milvus
分布式能力较强，适合大规模生产场景。

### Qdrant
API 体验好，过滤能力和部署方式灵活，社区活跃。

### Weaviate
功能完整，支持向量检索与知识对象管理，适合一体化方案。

## 这一章的代码项目
本章建议做一个最小可运行流程：

```text
documents
	↓
chunk
	↓
embedding
	↓
FAISS
	↓
保存 index
```

查询流程：

```text
用户问题
	↓
embedding
	↓
FAISS similarity search
	↓
Top-K chunks
```

下面给一个简化版示例（用于学习流程，不是生产级代码）：

```python
from sentence_transformers import SentenceTransformer
import faiss
import numpy as np
import pickle

# 1) 准备 chunk（假设已完成文档切分）
chunks = [
	 "Python 是一种通用编程语言，语法简洁。",
	 "Python 常用于数据分析、机器学习和自动化。",
	 "RAG 将检索与生成结合，提高答案准确性。"
]

# 2) 文本向量化
model = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")
embeddings = model.encode(chunks, normalize_embeddings=True)

# 3) 建立 FAISS 索引（内积；归一化后可视作余弦相似）
dim = embeddings.shape[1]
index = faiss.IndexFlatIP(dim)
index.add(np.array(embeddings, dtype=np.float32))

# 4) 保存索引和原始文本映射
faiss.write_index(index, "rag_demo.index")
with open("rag_demo_chunks.pkl", "wb") as f:
	 pickle.dump(chunks, f)

# 5) 查询
query = "Python 主要用在哪些领域？"
q_vec = model.encode([query], normalize_embeddings=True).astype(np.float32)
scores, ids = index.search(q_vec, k=2)

print("Top-K chunks:")
for rank, idx in enumerate(ids[0], start=1):
	 print(f"{rank}. score={scores[0][rank-1]:.4f} | {chunks[idx]}")
```

学习重点：
1. 先打通端到端链路，再优化细节。
2. 观察 chunk 质量如何影响召回结果。
3. 后续可加入 metadata 过滤、重排序和重构 Prompt。
