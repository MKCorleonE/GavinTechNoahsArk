## Embedding 是什么
Embedding 可以理解为“把文本映射成数字坐标”的过程。

例如一句话“Python 适合数据分析”，经过 embedding 模型后，会变成一个高维向量（如 768 维、1024 维）。

RAG 里为什么需要 embedding：
1. 计算机更擅长比较数字而不是直接比较自然语言。
2. 语义相近的文本，在向量空间中通常也更接近。
3. 可以支持快速语义检索（不是只靠关键词匹配）。


## 向量是什么
向量是一个有序数字列表，例如：

```text
[0.12, -0.45, 0.98, ...]
```

在 NLP 里，这些数字不是随便生成的，而是模型学习到的语义表示。不同文本会对应不同向量。

## 向量维度是什么
向量维度就是这个数字列表的长度。

例如：
1. 384 维：每个向量有 384 个数。
2. 768 维：每个向量有 768 个数。
3. 1536 维：每个向量有 1536 个数。

维度越高，理论上能表达更细粒度信息，但也会带来更高存储与计算成本。工程上要平衡效果与性能。

## Cosine Similarity（余弦相似度）
余弦相似度（Cosine Similarity）用于衡量两个向量的方向一致性，本质是两个向量夹角的余弦值。

### 详细定义
给定两个向量 $\mathbf{a}$ 和 $\mathbf{b}$，余弦相似度定义为：

$$
\cos(\theta)=\frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|\,\|\mathbf{b}\|}
$$

其中：
1. $\mathbf{a}\cdot\mathbf{b}$ 是点积。
2. $\|\mathbf{a}\|$ 和 $\|\mathbf{b}\|$ 是向量的 L2 范数（长度）。
3. $\theta$ 是两个向量的夹角。

当向量不为零向量时，余弦相似度取值范围是 $[-1,1]$：
1. $1$：方向完全一致。
2. $0$：方向正交（几乎无相关）。
3. $-1$：方向完全相反。

### 理论解释（为什么它适合文本检索）
在 embedding 空间里，向量的长度可能受句子长度、词频或模型尺度影响，但我们往往更关心语义方向是否一致。余弦相似度通过除以两个向量的长度，弱化了模长影响，突出方向信息。

因此在语义检索里，常优先用余弦相似度而不是直接比较欧氏距离。

### 数学展开式
如果

$$
\mathbf{a}=(a_1,a_2,\dots,a_n),\quad \mathbf{b}=(b_1,b_2,\dots,b_n)
$$

则

$$
\mathbf{a}\cdot\mathbf{b}=\sum_{i=1}^{n}a_i b_i
$$

$$
\|\mathbf{a}\|=\sqrt{\sum_{i=1}^{n}a_i^2},\quad
\|\mathbf{b}\|=\sqrt{\sum_{i=1}^{n}b_i^2}
$$

所以

$$
\cos(\theta)=\frac{\sum_{i=1}^{n}a_i b_i}{\sqrt{\sum_{i=1}^{n}a_i^2}\sqrt{\sum_{i=1}^{n}b_i^2}}
$$

### 例子 1：二维向量
设

$$
\mathbf{a}=(1,2),\quad \mathbf{b}=(2,1)
$$

计算：

$$
\mathbf{a}\cdot\mathbf{b}=1\times2+2\times1=4
$$

$$
\|\mathbf{a}\|=\sqrt{1^2+2^2}=\sqrt{5},\quad
\|\mathbf{b}\|=\sqrt{2^2+1^2}=\sqrt{5}
$$

$$
\cos(\theta)=\frac{4}{\sqrt{5}\sqrt{5}}=\frac{4}{5}=0.8
$$

结论：相似度较高，方向比较接近。

### 例子 2：三维向量
设

$$
\mathbf{a}=(1,0,1),\quad \mathbf{b}=(1,1,0)
$$

计算：

$$
\mathbf{a}\cdot\mathbf{b}=1\times1+0\times1+1\times0=1
$$

$$
\|\mathbf{a}\|=\sqrt{1^2+0^2+1^2}=\sqrt{2},\quad
\|\mathbf{b}\|=\sqrt{1^2+1^2+0^2}=\sqrt{2}
$$

$$
\cos(\theta)=\frac{1}{\sqrt{2}\sqrt{2}}=\frac{1}{2}=0.5
$$

结论：有一定相关性，但方向相似程度中等。

### 例子 3：n 维向量（通用）
设

$$
\mathbf{a}=(a_1,a_2,\dots,a_n),\quad \mathbf{b}=(b_1,b_2,\dots,b_n)
$$

则直接代入通用公式：

$$
\cos(\theta)=\frac{\sum_{i=1}^{n}a_i b_i}{\sqrt{\sum_{i=1}^{n}a_i^2}\sqrt{\sum_{i=1}^{n}b_i^2}}
$$

工程里通常用矩阵库一次性批量计算 query 与所有 chunk 向量的余弦相似度，再取 Top-K 作为召回结果。

### 实践注意点
1. 零向量无法计算余弦相似度（分母为 0），要在数据预处理时避免。
2. 若向量先做 L2 归一化，则余弦相似度等价于点积，检索实现更高效。
3. Top-K 检索时，相似度排序应与索引度量方式保持一致（cosine、IP、L2 不要混用）。

```python
import math

def manual_cosine_similarity(vec_a, vec_b):
    """
    纯手工实现余弦相似度，打印每一步的计算细节
    """
    # 1. 计算点积 (分子)
    dot_product = 0
    for i in range(len(vec_a)):
        dot_product += vec_a[i] * vec_b[i]
    print(f"步骤1: 点积 (分子) = {dot_product}")

    # 2. 计算向量A的模长 (分母的一部分)
    norm_a = 0
    for val in vec_a:
        norm_a += val ** 2
    norm_a = math.sqrt(norm_a)
    print(f"步骤2: 向量A的模长 = {norm_a:.4f}")

    # 3. 计算向量B的模长 (分母的一部分)
    norm_b = 0
    for val in vec_b:
        norm_b += val ** 2
    norm_b = math.sqrt(norm_b)
    print(f"步骤3: 向量B的模长 = {norm_b:.4f}")

    # 4. 计算最终相似度
    similarity = dot_product / (norm_a * norm_b)
    print(f"步骤4: 最终相似度 = {similarity:.4f}")
    return similarity

# 举例：两个向量
vec_a = [1, 2, 3]
vec_b = [4, 5, 6]

print("向量A:", vec_a)
print("向量B:", vec_b)
print("--- 计算过程 ---")
similarity = manual_cosine_similarity(vec_a, vec_b)
```

## Euclidean Distance（欧氏距离）
欧氏距离（Euclidean Distance）衡量两个向量在几何空间中的直线距离。

### 详细定义
给定两个向量 $\mathbf{a}$ 和 $\mathbf{b}$，欧氏距离定义为：

$$
d(\mathbf{a},\mathbf{b})=\|\mathbf{a}-\mathbf{b}\|_2
$$

展开后：

$$
d(\mathbf{a},\mathbf{b})=\sqrt{\sum_{i=1}^{n}(a_i-b_i)^2}
$$

它的取值范围是 $[0,+\infty)$：
1. 距离越小，两个向量越接近。
2. 距离为 0，两个向量完全相同。
3. 距离越大，差异越大。

### 理论解释
欧氏距离直接比较“位置差”，所以会同时受方向和长度影响。在文本向量场景里，如果向量尺度差异很大，欧氏距离可能被模长主导，因此常配合归一化使用。

### 例子 1：二维向量
设

$$
\mathbf{a}=(1,2),\quad \mathbf{b}=(4,6)
$$

$$
d=\sqrt{(1-4)^2+(2-6)^2}=\sqrt{9+16}=5
$$

### 例子 2：三维向量
设

$$
\mathbf{a}=(1,0,3),\quad \mathbf{b}=(4,0,-1)
$$

$$
d=\sqrt{(1-4)^2+(0-0)^2+(3-(-1))^2}=\sqrt{9+0+16}=5
$$

### 例子 3：n 维向量（通用）
设

$$
\mathbf{a}=(a_1,a_2,\dots,a_n),\quad \mathbf{b}=(b_1,b_2,\dots,b_n)
$$

$$
d(\mathbf{a},\mathbf{b})=\sqrt{\sum_{i=1}^{n}(a_i-b_i)^2}
$$

### Python 手动实现
```python
import math

def manual_euclidean_distance(vec_a, vec_b):
    if len(vec_a) != len(vec_b):
        raise ValueError("向量维度不一致")

    sum_sq = 0.0
    for i in range(len(vec_a)):
        diff = vec_a[i] - vec_b[i]
        sum_sq += diff * diff
    return math.sqrt(sum_sq)

# 2D
print(manual_euclidean_distance([1, 2], [4, 6]))   # 5.0
# 3D
print(manual_euclidean_distance([1, 0, 3], [4, 0, -1]))  # 5.0
# nD
print(manual_euclidean_distance([1, 2, 3, 4], [2, 1, 5, 0]))
```

## Dot Product（点积）
点积（Dot Product）是两个向量对应元素乘积之和，常用来衡量方向一致程度和投影关系。

### 详细定义
给定

$$
\mathbf{a}=(a_1,a_2,\dots,a_n),\quad \mathbf{b}=(b_1,b_2,\dots,b_n)
$$

点积定义为：

$$
\mathbf{a}\cdot\mathbf{b}=\sum_{i=1}^{n}a_i b_i
$$

它也可以写成：

$$
\mathbf{a}\cdot\mathbf{b}=\|\mathbf{a}\|\,\|\mathbf{b}\|\cos(\theta)
$$

其中 $\theta$ 是两向量夹角。

### 理论解释
1. 点积大：通常表示方向更一致（且模长也较大）。
2. 点积为 0：向量正交。
3. 点积小于 0：方向更相反。

在向量检索中，若向量都做了 L2 归一化，则

$$
\mathbf{a}\cdot\mathbf{b}=\cos(\theta)
$$

此时点积与余弦相似度等价。

### 例子 1：二维向量
设

$$
\mathbf{a}=(1,2),\quad \mathbf{b}=(3,4)
$$

$$
\mathbf{a}\cdot\mathbf{b}=1\times3+2\times4=11
$$

### 例子 2：三维向量
设

$$
\mathbf{a}=(1,0,2),\quad \mathbf{b}=(2,1,3)
$$

$$
\mathbf{a}\cdot\mathbf{b}=1\times2+0\times1+2\times3=8
$$

### 例子 3：n 维向量（通用）
设

$$
\mathbf{a}=(a_1,\dots,a_n),\quad \mathbf{b}=(b_1,\dots,b_n)
$$

$$
\mathbf{a}\cdot\mathbf{b}=\sum_{i=1}^{n}a_i b_i
$$

### Python 手动实现
```python
def manual_dot_product(vec_a, vec_b):
    if len(vec_a) != len(vec_b):
        raise ValueError("向量维度不一致")

    s = 0.0
    for i in range(len(vec_a)):
        s += vec_a[i] * vec_b[i]
    return s

# 2D
print(manual_dot_product([1, 2], [3, 4]))  # 11
# 3D
print(manual_dot_product([1, 0, 2], [2, 1, 3]))  # 8
# nD
print(manual_dot_product([1, 2, 3, 4], [5, 6, 7, 8]))
```

## Dense Vector（稠密向量）
稠密向量（Dense Vector）是指大多数维度都有非零值的向量，通常由神经网络 embedding 模型直接生成。

### 详细定义
设向量维度为 $n$，非零元素个数为 $\text{nnz}(\mathbf{x})$，可定义“稠密度”为：

$$
\rho(\mathbf{x})=\frac{\text{nnz}(\mathbf{x})}{n}
$$

当 $\rho(\mathbf{x})$ 接近 1 时，可认为该向量是稠密的。

说明：稠密/稀疏没有绝对阈值，常根据任务和工程约定判断。

### 理论解释
1. 稠密向量常把语义信息分布在多个维度上，不依赖少量关键词维度。
2. 这种分布式表示通常对语义相似检索更友好。
3. 在 RAG 中，embedding 向量大多属于稠密向量。

### 例子 1：二维向量
$$
\mathbf{x}=(0.6,-1.2)
$$

这里 $n=2$，非零元素个数 $\text{nnz}=2$，所以

$$
\rho=\frac{2}{2}=1.0
$$

可视为稠密向量。

### 例子 2：三维向量
$$
\mathbf{x}=(0.3,0.8,-0.5)
$$

这里 $n=3$，$\text{nnz}=3$，

$$
\rho=\frac{3}{3}=1.0
$$

仍是典型稠密向量。

### 例子 3：n 维向量（通用）
若

$$
\mathbf{x}=(x_1,x_2,\dots,x_n),\quad \rho(\mathbf{x})=\frac{\text{nnz}(\mathbf{x})}{n}
$$

当 $\rho$ 较高（例如远高于 0.5）时，通常可视为稠密向量。

### Python 手动实现
```python
def count_nnz(vec, eps=1e-12):
    c = 0
    for v in vec:
        if abs(v) > eps:
            c += 1
    return c

def density(vec, eps=1e-12):
    if len(vec) == 0:
        raise ValueError("空向量")
    return count_nnz(vec, eps) / len(vec)

def is_dense_vector(vec, threshold=0.7, eps=1e-12):
    return density(vec, eps) >= threshold

# 2D
v2 = [0.6, -1.2]
print(density(v2), is_dense_vector(v2))

# 3D
v3 = [0.3, 0.8, -0.5]
print(density(v3), is_dense_vector(v3))

# nD
vn = [0.1, 0.0, -0.2, 0.5, 0.0, 0.7]
print(density(vn), is_dense_vector(vn))
```

## Sparse Vector（稀疏向量）
稀疏向量是大多数位置为 0、少数位置非零的向量。

典型来源：
1. TF-IDF
2. BM25 相关特征

特点：
1. 更偏关键词匹配。
2. 可解释性通常更强。
3. 常与稠密向量做混合检索（Hybrid Search）。

## 实践中常用的 Embedding 方法
### 说明
传统 NLP 里的"词嵌入"（Word Embedding，比如 Word2Vec）是把单个词映射成向量；而 RAG 中用的 Embedding 模型（比如 bge-large-zh）是把一整段文本（句子、段落）映射成向量，通常叫"文本嵌入"或"句向量"。两者原理类似，但粒度和用途不同。RAG 用的是后者。

### Emdedding 在 RAG 中的作用
1. 把文本 chunk 转换成向量，存入向量数据库。
2. 把用户问题转换成向量，作为检索的查询。
```
【离线索引阶段】
文档 chunk → Embedding 模型 → 向量 → 存入向量数据库

【在线查询阶段】
用户问题 → Embedding 模型（同一个！）→ 查询向量 → 检索器拿它去数据库做相似度匹配 → 返回 Top-K 文档
```

## Vector Database 是什么
向量数据库是专门用于存储向量并进行近邻检索的系统。传统的关系型数据库（如 MySQL）擅长精确匹配（比如查找 name='张三' 的记录），但面对 Embedding 生成的几百上千维的浮点数数组，传统数据库无法高效地计算它们之间的“空间距离”17。

向量数据库专门为了解决这个问题而生，它的核心能力包括：
- 存储向量：专门优化了高维数组的存储结构。
- 近似最近邻搜索（ANN）：当数据量达到千万级时，逐一计算距离太慢了。向量数据库内置了 HNSW、IVF 等高级索引算法，能在毫秒级时间内找出与查询向量最接近的 Top-K 个结果29。
- 元数据过滤：支持在向量检索的同时，结合业务字段（如“仅检索2024年发布的文档”）进行混合过滤。

它一般提供：
1. 向量写入和更新。
2. 相似度检索（Top-K）。
3. 元数据过滤（如按文档类型、时间、部门过滤）。
4. 索引能力（如 HNSW、IVF 等）以提升检索速度。

### 检索器必须在 Vector Database 中运行吗？
不需要。检索器（Retriever）本质上是一个“调度员”，它负责调用 Embedding 模型、执行相似度计算并返回结果。这个“调度员”可以在以下三种不同的环境中运行：
- 运行在专业的 Vector Database 中（主流生产方案）
这是目前企业级 RAG 应用最标准的做法。检索器通过 SDK/API 与专业的向量数据库交互。
    - 特点：专为高并发、大规模数据设计，检索速度极快。
    - 代表：Milvus、Qdrant、Weaviate 等。
- 运行在带有向量插件的关系型数据库中（轻量级/复用方案）
如果你不想引入新的数据库组件，很多传统数据库现在也支持向量检索。检索器通过 SQL 语句直接查询。
    - 特点：开发效率极高（SQL一把梭），适合数据量不大、已有 PG 生态的项目。但超大规模下性能有瓶颈10。
    - 代表：PostgreSQL + pgvector、Neo4j（图数据库+向量）28。
- 运行在内存中或本地文件系统（原型/测试方案）
在写 Demo 或做小规模测试时，检索器可以直接把向量加载到内存里计算。
    - 特点：零配置，启动极快，但程序一关数据就丢了，且无法处理海量数据10。
    - 代表：LangChain 的 MemoryVectorStore、Chroma（本地模式）、FAISS（纯索引库）

## 这一章的代码项目
本章建议做一个最小可运行流程：

```text
documents
	↓
chunk
	↓
embedding
	↓
FAISS
	↓
保存 index
```

查询流程：

```text
用户问题
	↓
embedding
	↓
FAISS similarity search
	↓
Top-K chunks
```

下面给一个简化版示例（用于学习流程，不是生产级代码）：

```python
from sentence_transformers import SentenceTransformer
import faiss
import numpy as np
import pickle

# 1) 准备 chunk（假设已完成文档切分）
chunks = [
	 "Python 是一种通用编程语言，语法简洁。",
	 "Python 常用于数据分析、机器学习和自动化。",
	 "RAG 将检索与生成结合，提高答案准确性。"
]

# 2) 文本向量化
model = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")
embeddings = model.encode(chunks, normalize_embeddings=True)

# 3) 建立 FAISS 索引（内积；归一化后可视作余弦相似）
dim = embeddings.shape[1]
index = faiss.IndexFlatIP(dim)
index.add(np.array(embeddings, dtype=np.float32))

# 4) 保存索引和原始文本映射
faiss.write_index(index, "rag_demo.index")
with open("rag_demo_chunks.pkl", "wb") as f:
	 pickle.dump(chunks, f)

# 5) 查询
query = "Python 主要用在哪些领域？"
q_vec = model.encode([query], normalize_embeddings=True).astype(np.float32)
scores, ids = index.search(q_vec, k=2)

print("Top-K chunks:")
for rank, idx in enumerate(ids[0], start=1):
	 print(f"{rank}. score={scores[0][rank-1]:.4f} | {chunks[idx]}")
```

学习重点：
1. 先打通端到端链路，再优化细节。
2. 观察 chunk 质量如何影响召回结果。
3. 后续可加入 metadata 过滤、重排序和重构 Prompt。
